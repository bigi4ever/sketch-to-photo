# מציור לתמונה

אפליקציה לטלפון: מציירים סקיצה על הלוח, לוחצים "צור תמונה", ובינה מלאכותית הופכת את הציור לתמונה ריאליסטית עם אותם אלמנטים ובאותו סידור.

**כתובת:** https://bigi4ever.github.io/sketch-to-photo/

- פותחים את הכתובת בטלפון ומתקינים: באנדרואיד ב-Chrome ← ⋮ ← "התקנת אפליקציה", ובאייפון ב-Safari ← שיתוף ← "הוסף למסך הבית".
- בפעם הראשונה פותחים את ⚙️ ובוחרים שירות:
  - **Cloudflare (חינם)**: עשרות תמונות ביום. מקימים פעם אחת שרת קטן לפי [ההוראות](CLOUDFLARE.md).
  - **Google Gemini** או **OpenAI**: בתשלום, בערך 4 סנט לתמונה. ב-Gemini צריך להפעיל חיוב ב-AI Studio, כי התוכנית החינמית לא כוללת יצירת תמונות.
- ההגדרות נשמרות רק בטלפון, והציור נשלח רק לשירות שנבחר.

## קבצים
- `index.html`: כל האפליקציה (ציור, הגדרות, שליחה לשירותים).
- `cloudflare-worker.js`: הקוד של השרת ב-Cloudflare.
- `CLOUDFLARE.md`: הוראות הקמה של השרת.
- `manifest.webmanifest`, `sw.js`, `icons/`: התקנה בטלפון ועבודה בלי אינטרנט.
